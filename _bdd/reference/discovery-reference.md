# Example Mapping Miro Template

Introduce the Miro template for specification workshops, which includes placeholders for stories, rules, examples, 
and open questions or assumptions.

This template can be used to facilitate structured discussions during discovery sessions, ensuring that all relevant
aspects of the story or requirement are captured and organized effectively:

- [Example Mapping Template](https://miro.com/templates/example-mapping/)

## User Story Maps for Jira

Introduce the User Story Maps for Jira plugin, which allows teams to create and manage user story maps directly within Jira:
- [User Story Maps for Jira](https://marketplace.atlassian.com/apps/1220925/user-story-maps-for-jira)

## BDD for Jira

Introduce the BDD for Jira plugin, which allows teams to write and manage their BDD scenarios directly within Jira:

- [BDD for Jira](https://sharedspec.atlassian.net/wiki/spaces/BFJ/overview?homepageId=27394279)
- [BDD for Jira Documentation](https://sharedspec.atlassian.net/wiki/spaces/BFJ/overview?homepageId=27394279)

There is also a version of the app that integrates with Git:
- [BDD for Jira with Git Integration](https://marketplace.atlassian.com/apps/1236786/bdd-for-jira-with-git)
