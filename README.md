## Installation

Install [Ruby](https://www.ruby-lang.org/en/downloads/) on your system:

```shell
sudo apt install rbenv
```
Set up your shell to load rbenv:

```shell
rbenv init
```

See [rbenv](https://github.com/rbenv/rbenv) for detailed installation instructions on Ubuntu systems.

Install Jekyll and Bundler:

- [Installation on Ubuntu systems](https://jekyllrb.com/docs/installation/ubuntu/):
- [Installation on macOS](https://jekyllrb.com/docs/installation/macos/)

## Build the site and make it available on a local server

```shell
bundle exec jekyll serve
```
